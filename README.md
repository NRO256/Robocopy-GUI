## 1. 概要

Robocopy-GUI は、Windows 11 標準の高速・高信頼ファイルコピーコマンド（`C:\Windows\System32\robocopy.exe`）を、安全に操作できる軽量ポータブル Win32 GUI ラッパーです。
レジストリを一切使用せず、単一実行ファイル（`Robocopy-GUI.exe`）と同階層の設定ファイル（`Robocopy-GUI_config.json`）およびログフォルダ（`logs/`）のみで完結します。また、通常起動時の二重起動を抑止し、既存ウィンドウを前面化します。

## 2. 主な機能・特徴

### プリセット管理・ジョブ名・未保存検知

- よく使うコピー設定・除外設定をプリセットとして保存・切替・削除できます。設定変更時は「上書き保存*」で未保存状態を表示します。
- ジョブ名欄が空または「既定」のままキューへ追加した場合は、フォルダ名から「Src -> Dst」形式で自動命名します。
- メニューバーの「プリセット実行(&R)」から登録済みプリセットをワンクリックで即実行できます。

### パス指定・ドラッグ＆ドロップ・リアルタイム診断

- エクスプローラーからのドラッグ＆ドロップ（コピー元・コピー先・`/XD`・`/XF` 欄への個別ドロップ、またはウィンドウへの2フォルダ同時ドロップ）に対応しています。
- コピー元の実在確認とコピー先ドライブの空き容量・総容量をリアルタイム表示し、「開く」ボタンからエクスプローラーで即確認できます。「参照...」ダイアログは入力中フォルダ（または親フォルダ）を初期選択します。
- 同一パス、親子包含関係（相互配下）、存在しないコピー元、空フォルダを元にした `/MIR`、ドライブ直下・共有ルート・システム重要フォルダへの破壊的操作を事前ブロックします。

### コピーモード・補助オプション

- `/E`（空フォルダ含む）、`/S`（空フォルダ除外）、`/MIR`（ミラーリング）、`/MOVE`（移動）、`/XJ`（ジャンクション除外・既定 ON）、`/FFT`（NAS/FAT 向け2秒粒度比較）、`/Z`、`/ZB`、`/B`、`/SEC` を設定できます。
- 各オプションにツールチップ解説と入力例プレースホルダーを備えています。

### 除外設定・パフォーマンス設定

- `/XD`（セミコロンまたは改行区切り、空白を含むフォルダ名も分割しません）、`/XF`（除外ファイルパターン）、`/XA`（隠し・システム属性除外）、`/MT`（1〜128 スレッド）、`/R`・`/W`、`logs/` 自動保存、`/NP`、`/V`、追加カスタム引数を設定できます。
- よく使う除外ボタン（`+.git` / `+node_modules` 等）はトグル切替と「✓」有効表示に対応します。
- `/REG`、`/MON`、`/MOT`、`/RH`、`/QUIT`、`/LOG` 系など危険・競合する引数はブロックします。

### バックアップキュー（複数ジョブ順次実行）

- 複数ジョブを登録し、チェックボックス、操作ツールバー（読込・複製・上/下・削除・全消去・全選択/解除）、右クリックメニュー、ダブルクリック読込、キーボードで管理し、有効な項目を1件ずつ直列実行します。
- 途中エラー時の続行・停止を切り替えられます。

### テスト実行（ドライラン `/L`）・進捗表示・破壊的操作確認

- 実際の変更・削除を行わずに事前確認できる「テスト実行（ドライラン /L）」ボタンと進捗バーを備えています。
- `/MIR`・`/MOVE`・`/MOV`・`/PURGE` や完了後シャットダウン有効時の本実行前には確認ダイアログ（キャンセル既定）を表示し、実行中は `SetThreadExecutionState` によりスリープを抑止します。

### 完了後 PC シャットダウン（非永続・60秒カウントダウン）

- 「今回のみ・非永続」チェックボックスとして提供し、起動時・プリセット切替時は必ず OFF に初期化されます。
- テスト実行（`/L`）、ユーザー中止、または終了コード 8 以上のエラー発生時はシャットダウンを行いません。
- 正常完了時のみ設定・ログを保存した後、60秒カウントダウンダイアログを表示し、`Esc` キーまたは「シャットダウンを中止」ボタンで即時キャンセルできます。

### バッチファイル（`.bat`）エクスポート・ログ管理

- 単発またはキュー全体を `UTF-8 (chcp 65001) + CRLF` 形式で出力します。
- 実行ログタブからワンクリックでログ全文のコピーや `logs/` フォルダの開封が行えます。ログは最大 50 ファイル保持します。

### 管理者として再起動（UAC 昇格）

- メニュー「ツール」→「管理者として再起動」から編集状態・キューを引き継いで管理者権限で再起動できます。

### 視認性・高DPI対応

- 3タブ構成（基本・除外設定 / バックアップキュー / 実行ログ）、PerMonitorV2 高DPI、およびコマンドプレビュー・実行ログ欄の等幅フォント（`BIZ UDGothic`）表示に対応しています。

## 3. 動作環境

- OS: Windows 11 (64bit)
- 権限: 通常権限で動作します（システム保護領域やアクセス権が必要なコピーのみ、メニューから管理者として再起動できます）
- ランタイム・インストール: 追加ランタイム不要、インストール不要、レジストリ不使用（完全ポータブル）

## 4. ダウンロード・使い方

### 導入手順

1. GitHub Releases（https://github.com/NRO256/Robocopy-GUI/releases）から `Robocopy-GUI-v0.2.0-win.zip` をダウンロードします。
2. ダウンロードした ZIP ファイルを任意の書き込み可能なフォルダへ展開します。
3. 展開先フォルダ内の `Robocopy-GUI.exe` を起動します。初回起動時に Windows Defender SmartScreen（「WindowsによってPCが保護されました」）が表示された場合は、「詳細情報」をクリックして「実行」を選択してください。

### 基本操作

1. 「基本・除外設定」タブでコピー元・コピー先とコピーモード・除外設定を指定します（登録済みのプリセットから切り替えることもできます）。
2. まず「テスト実行（/L）」をクリックし、コマンドプレビューと実行ログでコピー・削除予定の対象に誤りがないか確認します。
3. 問題がなければ「本実行」をクリックするか、複数ジョブを「バックアップキュー」へ追加して順次実行します。

## 5. キーボード操作・スクリーンリーダー（NVDA / ナレーター）対応

- `Tab` / `Shift+Tab`: 全コントロールを順番に移動します。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` または `Ctrl+1`〜`3`: タブ（基本・除外設定 / バックアップキュー / 実行ログ）を切り替えます。
- `Ctrl+A`: テキスト入力欄・ログ欄で全文を選択します。
- `Ctrl+S`: 設定を保存します。
- `Ctrl+E`: バッチファイル（`.bat`）を出力します。
- `Alt+F`（ファイル）、`Alt+R`（プリセット実行）、`Alt+T`（ツール）、`Alt+H`（ヘルプ）: メニューバーを開きます。
- キュー一覧での操作: `Space` で有効/無効チェック切替、ダブルクリックまたは「フォームへ読込」で編集欄へ読込、`Delete` で削除、`Alt+↑` / `Alt+↓` で順序を移動します。

## 6. robocopy 終了コードの目安

- `0`〜`7`: 正常終了（`0`: 変更なし、`1`: コピー成功、`2`: 余分検出、`4`: 不一致検出）
- `8`以上: 異常終了（`8`: コピー失敗あり、`16`: 致命的エラー）

## 7. 注意事項・免責

- `/MIR`（ミラーリング）や `/MOVE`（移動）、`/PURGE` を含む設定はコピー先のファイル削除や移動元の削除を伴います。初回実行時やパス変更時は必ず「テスト実行（/L）」で事前確認してください。
- 管理者権限へ再起動してネットワークドライブを扱う場合は、OS のセッション分離によりマップドドライブ（`Z:\` 等）が認識されない場合があるため、UNC パス（`\\Server\Share`）での指定を推奨します。
- 本ソフトウェアの利用により生じたデータ損失等の損害について、作成者は責任を負いかねます。事前のテスト実行と重要なデータのバックアップ確認を推奨します。
