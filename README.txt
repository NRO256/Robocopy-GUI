1. 概要
  Robocopy-GUI は、Windows 11 標準の高速・高信頼ファイルコピーコマンド
  （C:\Windows\System32\robocopy.exe）を、安全に操作できる軽量ポータブル
  GUI ラッパーです。
  レジストリを一切使用せず、単一実行ファイル（Robocopy-GUI.exe）と同階層の
  設定ファイル（Robocopy-GUI_config.json）およびログフォルダ（logs/）のみで
  完結します。

2. 主な機能
  - プリセット管理:
    よく使うコピー設定・除外設定をプリセットとして保存・切替・削除できます。
  - パス指定と安全保護:
    「コピー元」「コピー先」の同一パス、親子包含関係（相互配下）、存在しない
    コピー元、空フォルダを元にした /MIR、ドライブ直下・共有ルート・システム
    重要フォルダへの破壊的操作を事前ブロックします。
  - コピーモード・補助オプション:
    /E（空フォルダ含む）、/S（空フォルダ除外）、/MIR（ミラーリング）、
    /MOVE（移動）、/XJ（ジャンクション除外・既定ON）、/FFT（NAS/FAT向け
    2秒粒度比較）、/Z、/ZB、/B、/SEC を設定できます。
  - 除外設定・パフォーマンス設定:
    /XD（セミコロンまたは改行区切り、空白含むフォルダ名も分割しません）、
    /XF（除外ファイルパターン）、/XA（隠し/システム属性除外）、/MT（1〜128）、
    /R・/W、logs/ 自動保存、/NP、/V、追加カスタム引数を設定できます。
    （/REG、/MON、/MOT、/RH、/QUIT、/LOG 系など危険・競合引数はブロック）
  - バックアップキュー（複数ジョブ順次実行）:
    複数ジョブを登録し、チェックボックスで有効・無効切替、上下並替を行い、
    1件ずつ直列実行します。途中エラー時の続行/停止も切替可能です。
  - テスト実行（ドライラン /L）と破壊的操作確認:
    実際の変更・削除を行わずに事前確認できるテスト実行ボタンを備えています。
    /MIR・/MOVE・/MOV・/PURGE や完了後シャットダウン有効時の本実行前には
    確認ダイアログを表示します。
  - 完了後 PC シャットダウン（非永続・60秒カウントダウン）:
    「今回のみ・非永続」チェックボックスとして提供し、起動時・プリセット切替時は
    必ず OFF に初期化されます。テスト実行（/L）、ユーザー中止、または終了コード
    8以上のエラー発生時はシャットダウンを行いません。
    正常完了時のみ設定・ログを保存した後、60秒カウントダウンダイアログを表示し、
    Esc キーまたは「シャットダウンを中止」ボタンで即時キャンセルできます。
  - バッチファイル（.bat）エクスポート:
    単発またはキュー全体を UTF-8（chcp 65001）+ CRLF 形式で出力します。
  - 管理者として再起動（UAC昇格）:
    メニュー「ツール」→「管理者として再起動」から編集状態・キューを引き継いで
    管理者権限で再起動できます（マップドドライブ使用時はUNC指定を推奨）。

3. キーボード操作・スクリーンリーダー（NVDA）対応
  - Tab / Shift+Tab で全コントロールを順番に移動できます。
  - Ctrl+S: 設定を保存 / Ctrl+E: バッチファイル(.bat)出力
  - Alt+F（ファイル）、Alt+T（ツール）、Alt+H（ヘルプ）でメニューを開けます。
  - キュー一覧では Space キーでジョブの有効/無効チェックを切り替えられます。

4. robocopy 終了コードの目安
  - 0〜7: 正常終了（0:変更なし、1:コピー成功、2:余分検出、4:不一致検出）
  - 8以上: 異常終了（8:コピー失敗あり、16:致命的エラー）

5. 動作環境・ファイル構成
  - 動作環境: Windows 11 (64bit)
  - 構成ファイル:
    Robocopy-GUI.exe          本体実行ファイル
    Robocopy-GUI_config.json  設定・プリセット・キュー保存ファイル（自動生成）
    logs\                     実行ログ自動保存フォルダ（最大50ファイル保持）
